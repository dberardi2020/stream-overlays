# Catalogue archive

Where the overlay set was worked out. These are the **superseded early drafts** of the catalogue — the exploratory pages that preceded the current source of truth (`../catalogue.json`) and the [gallery](../pages/gallery.html). Kept for provenance: they show how the designs and the direct-vs-telemetry split were arrived at. They are **not** live and nothing depends on them.

Each is a self-contained HTML page (single-format — data-embedded, no Markdown form):

| Draft | What it explored |
| --- | --- |
| `v1-shifter-steering-combined.html` | First pass at combining shifter + steering visuals. |
| `v2-direct-vs-telemetry.html` | The split that became [principle 1](../design-principles.md) — direct rig data vs game telemetry. |
| `v3-shifter-steering-combined.html` | A later combined-layout iteration. |

For the current designs, read [`../design-principles.md`](../design-principles.md) and browse the [gallery](../pages/gallery.html).

Rig Setup

Calibrate your rig once, here — pedals, steering, and shifter. Calibration is saved in this browser (it's intrinsic to your physical hardware), so the gallery's Live mode and your overlays in this same browser pick it up automatically.

○ no device detected

Pedals

Press any wheel button first so the browser sees the device. Then release everything for neutral and press each pedal fully — travel scales to your hardware.

Wheel

Sweep fully left, then fully right, then re-centre.

Shifter

Calibrate an H-Shifter (shift into each gear) or Paddles / a Sequential shifter (capture upshift + downshift — both report as the same up/down pair).

Start over

Wipes every channel in this browser — pedals, wheel and both shifter controls — and forgets the saved calibration entirely. The Clear button inside each box is the normal way to redo just one thing; this is the full reset.

Telemetry later

RPM, speed, and gear-from-sim are telemetry, not wheel input — a G923 doesn't expose them. Deferred to a later milestone (SO-0007); telemetry overlays run on demo data until a sim feed exists.

Using it in OBS

OBS is a separate browser. Calibrating here in Chrome does not carry over — OBS keeps its own storage, so a rig calibrated on this page still reads not set over there. It needs its own one-time calibration. That is the step everyone misses.

The local server must be running whenever OBS loads a source. Overlay URLs are http://localhost:8000/… and resolve only while it is up — if it isn't, the overlay is silently blank, mid-stream. Double-click scripts/start-overlays.cmd, or put a shortcut to it in your Startup folder (Win+R → shell:startup) so it is always up.

Calibrate inside OBS — once

Easiest: download a ready-made scene collection with the source already set up — right URL, right size, and Shutdown when not visible already off — then in OBS use Scene Collection → Import and switch to it.

Then just right-click the source → Interact, click once on the page, and press a wheel button. Skip to step 4 below.

Or set it up by hand

  1. Add a Browser Source with this URL, sized about 900 × 1000:
    …
    The ?obs=1 drops the site nav and this section — neither means anything inside OBS.
  2. Untick Shutdown source when not visible — a backgrounded page can't hold the device.
  3. Right-click the source → Interact. A separate window opens.
  4. Click once on the page, then press any wheel button. The device line goes green — the Gamepad API only reports to a focused document, and Interact is what gives it focus.
  5. Calibrate pedals, wheel and shifter there, then delete the source (or switch back to your own scene collection). Every overlay in that OBS browser now reads the calibration.

Then add the overlays

  1. In the gallery, hit Copy OBS link on any overlay.
  2. Add it as a Browser Source at the size shown on its card — that is the real render size, not the design size, so don't let OBS stretch it.

One at a time is the only way for now. A collection containing every overlay sounds better, but OBS cannot copy or paste sources between scene collections — a long-standing missing feature — so a separate collection can't be a library you take things out of. Bulk import has to merge into your existing collection instead; that's SO-0033.

Still no device after Interact? Some setups never expose the gamepad to OBS's browser at all. Fall back to running the overlay in a real Chrome window and capturing it with OBS Window Capture — your Chrome calibration already works there.

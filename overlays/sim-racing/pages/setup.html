Wheel Setup

Calibrate your wheel once, here. Calibration is saved in this browser (it's intrinsic to your physical wheel), so the gallery's Live mode and any overlay.html in this same browser pick it up automatically. The overlay page itself has no setup — it's a pure renderer, so nothing here can ever end up on your stream.

Calibrate

Connect your wheel and press any button so the browser sees it, then Calibrate all — release everything for Neutral, then press each pedal fully. Steering is optional.

Shifter / gear next

H-shifter and paddle/gear binding — direct HID input, part of the v0 plan. Not wired yet; the slot is here so the shifter overlays can go live without a redesign (SO-0006).

Telemetry later

RPM, speed, and gear-from-sim are telemetry, not wheel input — a G923 doesn't expose them. Deferred to a later milestone (SO-0007); telemetry overlays run on demo data until a sim feed exists.

Using it in OBS

Overlays are a separate, pure page (overlay.html?style=<id>) — see the user guide. Because calibration is per-browser, OBS's built-in browser needs its own one-time calibration:

  1. Add this setup page as a temporary OBS Browser Source.
  2. Right-click it → Interact, press a wheel button, and calibrate here.
  3. Remove the setup source. Every overlay.html in that OBS browser now reads the saved calibration.

No device showing? The Gamepad API only wakes on a focused page — that's what the Interact window gives you. If it still won't appear, run the overlay in a real Chrome window and use OBS Window Capture instead (see ADR 0003).
